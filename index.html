Help & about
Tools
  • Select: click a node or edge, or drag on empty canvas to highlight an area and select everything it touches (Shift adds). On touch screens, drag one finger. Drag a selected item to move the whole selection.
  • Add node: click empty canvas to add a node. Double-clicking or double-tapping also adds one in Select and Connect.
  • Connect nodes: drag from one node to another, or click one and then the other.
  • Pan canvas: drag to move the view. The wheel, pinch and the zoom buttons zoom.
  • Delete: removes everything selected.

Select a single node or edge to rename it; edges also take a value, which the analysis uses as a weight. Graphs are simple: edges are undirected, with no loops or duplicates.

Header buttons
  • Undo / Redo: step back or forward through your edits.
  • New graph, Open, Save: clear the canvas, load a graph file, or download the graph as an image or data file. On phones these are in the menu.
  • Compare: opens a second workspace for comparing two graphs.
  • Settings: default names, labels, grid, dark mode and automatic analysis updates.
  • Analyze: metrics, Euler and Hamilton routes (with an example or the reason there is none), centrality, matrices and eigenvalues of the graph, updated as you edit.
Comparing two graphs
  • With two workspaces open, Analyze is replaced by Isomorphism, which checks whether the two graphs have the same structure. Analysis works on one graph at a time.
  • If they are isomorphic, it shows which node maps to which; if not, it explains why.
  • Click a workspace or its tab to make it active. New graph, Open, Save and Undo act on the active one; the tools apply to both.
  • Close a workspace with the on its tab to get Analyze back.
Keyboard shortcuts

Delete removes the selection · Esc clears it · Ctrl+Z undo · Ctrl+Y redo

About

GraphSandbox is a free tool for exploring graph theory by hand. The math runs in Python right in your browser, and your graphs never leave your device. More details are in the README.

Found a problem? You can report it on GitHub (a free GitHub account is needed).

If GraphSandbox is useful to you, support or a donation would be greatly appreciated.
